# Configuration

Les fichiers JSON de ce dossier contrôlent le portfolio.

- `site.json` : réglages généraux
- `profile.json` : profil GitHub
- `socials.json` : réseaux sociaux
- `categories.json` : catégories
- `projects.json` : projets
- `github-import.json` : import GitHub
- `theme.json` : thèmes et polices
- `views.json` : modes d'affichage
- `effects.json` : animations
- `navigation.json` : menu
- `docs.json` : documentation Markdown

Pour ajouter un dépôt, commencez par `projects.json`.
